# CampusHub
CampusHub - Student Academic Dashboard | Full Stack Web Development Mini Project
A simple and responsive Student Academic Dashboard developed as a mini project for the Full Stack Web Development course.

CampusHub provides students with a clean single-page interface to view their academic information such as courses, attendance, assignments, and profile details. The dashboard uses tab-based navigation, allowing users to switch between different sections without refreshing the webpage.

Features
Student login using Name and Register Number
Clean and responsive dashboard UI
Single-page tab-based navigation
Dashboard overview with academic statistics
Course information
Subject-wise attendance with progress bars
Assignment management
Assignment filtering by status
Student profile section
Light and Dark theme
Theme preference saved using Local Storage
Login information stored using Local Storage
Logout functionality
Responsive design for desktop, tablet, and mobile
Simple animations and transitions
Technologies Used
HTML5 – Structure of the web application
CSS3 – Styling, layout, responsiveness, and themes
JavaScript – Dynamic interaction and DOM manipulation
Local Storage – Storing login details and theme preference
Dashboard Sections
Dashboard

Provides an overview of the student's academic information, including attendance percentage, number of courses, pending assignments, completed assignments, recent assignments, and recent activities.

Courses

Displays the list of enrolled courses along with faculty, credits, and status.

Attendance

Shows subject-wise attendance percentages using simple progress bars.

Assignments

Displays assignments with their subject, due date, and completion status. Users can filter assignments by:

All
Pending
Completed
Profile

Displays the student's name, register number, department, year, class, and other basic information.
